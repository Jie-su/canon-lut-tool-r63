# License texts included with the release

The files in this directory are preserved upstream license and acknowledgment
texts. The project's own MIT license is in the repository root.

| File | Scope |
| --- | --- |
| `Python-3.13.3-LICENSE.txt` | PSF and historical Python license terms |
| `Python-3.13.3-History-and-License.rst` | Complete Python.org license document, including incorporated-software notices |
| `OpenSSL-3.0.16-LICENSE.txt` | Apache License 2.0 for bundled OpenSSL libraries |
| `ncurses-6.5-COPYING.txt` | ncurses 6.5 copyright and permission notice |
| `XZ-5.2.3-COPYING.txt` | XZ licensing summary identifying the included liblzma as public domain |

`SOURCES.json` records upstream locations and checksums. Read
`THIRD_PARTY_NOTICES.md` in the repository or application resources for the
runtime modification summary, component scope, and external-dependency notes.
The unmodified Python license document contains notices for a larger upstream
distribution; some of its components are excluded from this application's
minimized runtime.
